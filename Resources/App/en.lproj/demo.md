# MakeTools Markdown Preview

Open a Markdown file in MakeTools, or select it in Finder and press **Space** to preview it with Quick Look.

> [!TIP]
> Use the toolbar to copy the original Markdown or plain text. Code blocks have their own copy button.

## Text and lists

Use **bold**, *italic*, ~~strikethrough~~, and `inline code`.

- [x] Task lists
- [x] Nested lists
  - [x] Markdown links, such as the [Swift website](https://swift.org)
- [ ] Your next task

## Code

```swift
let tools = ["Calendar", "File transfer", "Markdown"]
for tool in tools {
    print(tool)
}
```
